# 動画とBGMの制作相談室

記事・アイデア・手持ちの素材から、5つの質問に答えて、AIエージェントに渡す制作の依頼文を作るWebアプリです。
BGMだけの相談にも対応しています。

https://shenyexiaoti-gif.github.io/video-prompt-studio/

## 使い方

1. 上のURLをスマホかPCのブラウザで開きます。スマホはホーム画面に追加できます。
2. 質問に答えて、最後に「依頼文を作成」を押します。
3. 依頼文をコピーして、PCの Claude Code や Codex に貼ると制作まで進められます。スマホの ChatGPT・Claude・Gemini に貼った場合は、手順の相談や台本づくりに使えます。

## このアプリがしないこと

- AIの呼び出し、動画や音楽の生成、課金はしません。依頼文を作るだけです。
- 入力した内容は、その端末のブラウザの中だけに保存します。外部には送りません。
